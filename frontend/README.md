# ShareList frontend

Angular 22 app (standalone components, signals, zoneless, Signal Forms).

```bash
npm install
npm start                  # http://localhost:4200, proxies /api to the backend on :8080
npm test -- --watch=false  # Vitest unit tests
npm run build              # production build in dist/frontend/browser
```

See the [main README](../README.md) for the full picture.
